Website chính thức của **Hội Khuyến Học Việt Nam** – tổ chức xã hội phi lợi nhuận với sứ mệnh nâng cao dân trí, đào tạo nhân lực và xây dựng xã hội học tập trên toàn quốc. Dự án được thiết kế với giao diện **5.0** hiện đại, tối ưu hóa cho cả thiết bị di động (hỗ trợ lập trình và xem trực tiếp trên **Acode**, **Trebedit**) lẫn máy tính.

---

## ✨ Tính Năng Nổi Bật (Giao Diện 5.0)

- 🎨 **Thiết kế Glassmorphism & Modern Minimalist:** Giao diện trực quan, sang trọng, sử dụng Tailwind CSS qua CDN mang lại trải nghiệm mượt mà.
- 📖 **Bài Viết Cốt Lõi:** Tích hợp đầy đủ nội dung về sứ mệnh, mục đích hoạt động và vai trò của Hội trong sự nghiệp giáo dục.
- 🔍 **Tra Cứu & Đăng Ký Học Bổng:** Cho phép học sinh, sinh viên tra cứu trạng thái nhận học bổng hoặc đăng ký xét duyệt trực tuyến.
- 🏛️ **Mô Hình Xã Hội Học Tập:** Giới thiệu chi tiết 4 mô hình trọng tâm: *Gia đình học tập, Dòng họ học tập, Cộng đồng học tập, Đơn vị học tập*.
- 💳 **Quỹ Khuyến Học & Ủng Hộ:** Cung cấp thông tin tài khoản ngân hàng và biểu mẫu đóng góp cho các nhà hảo tâm.
- 📱 **Tối Ưu Di Động Tuyệt Đối:** Hoạt động hoàn hảo trên các ứng dụng soạn thảo mã nguồn di động như **Acode** hoặc **Trebedit**.

## 🚀 Hướng Dẫn Sử Dụng & Chạy Thử

### 1. Chạy trên điện thoại (Acode / Trebedit)
1. Tải ứng dụng **Acode** hoặc **Trebedit** trên Google Play / App Store.
2. Tạo một file mới đặt tên là `index.html`.
3. Sao chép toàn bộ mã nguồn của website dán vào file `index.html`.
4. Sử dụng tính năng **Preview** (Xem trước) trong ứng dụng để trải nghiệm ngay lập tức.

### 2. Triển khai lên GitHub Pages (Miễn phí)
1. Tạo một Repository mới trên GitHub (Ví dụ: `hoi-khuyen-hoc-vn`).
2. Tải file `index.html` lên repository.
3. Vào phần **Settings** của repository -> Chọn mục **Pages**.
4. Tại mục **Build and deployment**, phần Branch chọn `main` (hoặc `master`) và thư mục `/ (root)` -> Bấm **Save**.
5. Sau vài phút, GitHub sẽ cung cấp một đường link trực tuyến để bạn truy cập vào website của mình.
